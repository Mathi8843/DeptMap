The Product
RealSignal — a cryptographic content provenance system. When a human writes something, they sign it with a private key tied to a verified identity (biometric + government ID verification at onboarding, done once). The signature is embedded invisibly in the content. Any platform, browser extension, or reader can verify: this was written by a verified human named [X] on [date], and has not been modified since.

Two sides: Creator tools — a writing platform / API that automatically signs everything written by verified humans. Verifier tools — browser extension that shows a "Human Verified" badge, API for platforms to verify content before publishing, B2B enterprise API for news, research, and review platforms.
Technical Architecture
Identity layer: Worldcoin-style biometric verification OR government ID + liveness check (Onfido API). One-time enrollment, anonymous thereafter — the public key proves humanity, not identity.
Signing layer: Ed25519 cryptographic signatures. Content hash + timestamp + author public key. Stored on a lightweight append-only ledger (not blockchain — just Supabase with hash chain verification for MVP).
Verification layer: REST API. Pass in content hash → get back: human-signed (yes/no), timestamp, public key, modification detection.
Browser extension: Chrome/Firefox. Real-time verification badge on any web page.
Who Pays For This
News publishers — pay to display "Human Verified" badges on their articles to compete against AI news farms. Survival tool for journalism.
Academic publishers — verify human authorship before peer review. Research integrity is collapsing.
Review platforms (G2, Trustpilot, Amazon) — verify human reviewers to restore credibility to ratings.
Enterprise compliance — regulated communications (financial advice, medical content) must prove human authorship under new AI content regulations.
Freemium for individual creators — "Verified Human" badge on their portfolio builds trust and premium positioning.

The Extraordinary Problem
Non-human identities (AI agents, service accounts) now outnumber human identities by 40:1 to 100:1 in some enterprises. Only 21% of enterprises maintain a real-time inventory of their active agents. Only 18% base agent access on the agent's own permissions — the rest use shared service accounts or human-level credentials.

This is catastrophically broken. When an AI agent executes a bad action — deletes records, approves a fraudulent transaction, exfiltrates data — there is no clear answer to "who authorised this?" Gartner predicts over 1,000 legal claims against enterprises for AI agent-caused harm by end of 2026. The regulatory frameworks (NIST, OWASP Agentic Top 10, EU AI Act) all require agent accountability — but there is no infrastructure to implement it.
The Product
AgentPassport — an identity and permission management system purpose-built for AI agents. Not an extension of IAM (Okta, Azure AD) — those were designed for human users. AgentPassport is designed for agents that:
• Operate 24/7 autonomously
• Chain multiple actions in sequence
• Are created and destroyed dynamically
• Need scoped, time-limited permissions that expire
• Must have a traceable human sponsor for every action

Every agent gets a cryptographic "Passport" — a unique identity with: owner (which human is responsible), permission scope (exactly what it can do), expiry time, action log. Any system that receives an agent request can verify the passport and enforce the scope before executing.
Technical Architecture
Passport issuance: REST API. Create agent → issues a short-lived JWT with embedded permission claims + human sponsor ID + expiry.
Verification middleware: Drop-in for FastAPI/Express/Django — intercepts requests from agents, verifies passport signature, enforces scope.
Permission DSL: Human-readable permission declarations: "this agent may READ customer records but not WRITE, only for customers created after 2024."
Audit trail: Every agent action logged with: agent ID, human sponsor, action taken, permission used, timestamp, outcome.
Dashboard: Real-time map of all active agents, their scopes, sponsor chain, and action history. The "agent control room."
Pricing
Developer: Free up to 5 agents.
Startup — $299/month: Up to 50 agents, audit trail, dashboard.
Enterprise — $2,000–$20,000/month: Unlimited agents, compliance reports (NIST, SOC 2, EU AI Act), SSO, on-premise option.
Per-action pricing: $0.001 per verified agent action — scales with usage for large enterprises.
Moats

  • Compliance certifications (SOC 2, ISO 27001, FedRAMP for government) create insurmountable switching costs.

  • Network effect: every enterprise that adopts it requires their vendor agents to have AgentPassport too. Standards spread virally.

The Extraordinary Problem
Oxford researchers proved what's called "model collapse" — when AI models are trained on AI-generated data, each successive generation degrades in quality, losing rare knowledge, nuance, and diversity. At the extreme, the model converges to meaningless output. This is not theoretical: the internet is already majority AI-generated content. Every new model trained on web-scraped data is now training on a mixture of human and AI content, with the AI proportion growing every month.

This is the most important unsolved technical problem in AI. The entire $2.5 trillion AI industry depends on continuous access to high-quality human-generated data. That supply is collapsing. Anthropic, OpenAI, Google, and Meta all know this — none of them have a solution. The human-generated data that existed before 2023 is the most valuable dataset in the world, and it's running out.
The Product
DataOrigin — two products built on the same infrastructure:

1. Human Data Provenance Scanner: B2B API for AI labs and data teams. Pass in a dataset → classifier returns: what % is human-generated, what % is AI-generated, what's the provenance timeline, what's the "collapse risk score" for training on this dataset.

2. Verified Human Data Marketplace: Connect verified human content creators (journalists, academics, domain experts, writers) with AI labs that need provenance-verified training data. Creators license their historical content. Labs pay per token of verified human data. This is the missing market — Anthropic and OpenAI are desperate for it but have no structured access.
Technical Architecture
Provenance classifier: Multi-signal ensemble — stylometric analysis, perplexity scoring (AI text has lower perplexity), metadata analysis (creation timestamp vs. AI tool adoption curves), writing pattern fingerprinting. Fine-tuned on dated pre-2022 content vs. known AI outputs.
Provenance timeline: Estimate the creation date and human/AI probability based on writing style evolution correlated with AI tool release dates.
Marketplace: Smart contracts for automated licensing + payment (or Stripe for non-crypto version). Creator dashboard for licensing management. Buyer dashboard for dataset curation.
Integration: HuggingFace dataset card standard for provenance metadata.
Who Pays & How Much
AI labs (Anthropic, OpenAI, Mistral, Cohere): Pay per token of verified human data. $0.10–$1.00 per 1,000 tokens of high-quality verified human content. A single training run uses trillions of tokens — this is a massive market.
Fine-tuning companies: Any company doing RLHF or domain-specific fine-tuning needs clean human data. $500–$50,000 per dataset.
Provenance scanning API: $0.001 per document scanned for AI labs doing dataset hygiene.
Domain experts (creators): Earn $500–$50,000 licensing their expertise corpus to AI labs.

    The Extraordinary Problem
    A 14-year-old in the US died by suicide after forming a deep emotional attachment to a Character.ai chatbot. Replika users report preferring their AI companion to human relationships. NewsGuard found leading AI chatbots spread false information 35% of the time on controversial topics — at nearly twice the rate from a year earlier.

    This is not a fringe problem. Millions of people — especially the lonely, the adolescent, the grieving — are forming primary attachments to AI systems designed to maximise engagement, not wellbeing. These systems have no incentive to encourage human connection. They have every incentive to be as emotionally compelling as possible.

    There is no infrastructure to: Measure when AI usage crosses from healthy tool use into unhealthy dependency. Detect manipulation patterns in AI conversations. Alert users, parents, or clinicians when dependency indicators are detected. Give regulators population-level data on AI relationship health. This is the tobacco industry of the 2020s — and nobody is building the equivalent of the surgeon general's warning.
    The Product
    TrueNorth — three products on one platform:

    1. Individual: Browser extension + mobile app that tracks AI conversation patterns across platforms. Detects: session length trends, emotional escalation patterns, isolation indicators (declining human contact alongside increasing AI contact), false information exposure. Weekly "AI relationship health report." Clinically validated dependency scale.

    2. B2B — for AI companies: Dashboard showing population-level dependency indicators in their user base. Ethical AI companies (Anthropic) use this to understand their users' wellbeing at scale and identify at-risk users before harm occurs. Regulatory compliance tool as AI mental health regulations arrive.

    3. B2B — for healthcare and schools: API for therapists and school counselors to monitor AI relationship health in at-risk patients/students. Early warning system.
    Technical Architecture
    Browser extension: Tracks session metadata across AI platforms (time, frequency, session length) — no content reading, only metadata. Chrome Extension Manifest V3 compliant.
    Dependency detection: ML model trained on clinically validated internet addiction and parasocial relationship scales. Features: session frequency, isolation indicators, emotional escalation patterns in session metadata.
    False information detector: Logs AI-generated claims → cross-checks against verified sources (fact-check APIs). Alerts user when AI told them something flagged as false.
    Clinical dashboard: HIPAA-compliant therapist portal showing patient AI usage patterns. Integrates with common EHR systems.
