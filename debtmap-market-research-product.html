Screen 02 · Issue Detail & AI Fix
Issue Detail — BOLA in /api/users/:id
What's wrong
🚨 Critical — Fix immediately
Your user profile endpoint lets any logged-in person read any other user's profile — not just their own. This is called Broken Object Level Authorization (BOLA) — the #1 most common vulnerability in vibe-coded apps.

In plain terms: if your user ID is user_123, any other logged-in user can change that to user_124 and see your data.
What could go wrong
❌ Users' emails, phone numbers, addresses exposed
❌ Subscription status and payment history visible
❌ GDPR / DPDP violation — potential legal liability
❌ If discovered publicly, users will leave immediately
The vulnerable code
// ❌ DANGEROUS — no ownership check
app.get('/api/users/:id', async (req, res) => {
  const user = await db.users.find(
    { id: req.params.id }
  );
  res.json(user); // ← no auth check!
});
The fix (AI-generated, ready to apply)
// ✓ SAFE — checks ownership
app.get('/api/users/:id', requireAuth, async (req, res) => {
  if (req.user.id !== req.params.id) {
    return res.status(403).json({error: 'Forbidden'});
  }
  const user = await db.users.find({ id: req.params.id });
  res.json(user);
});

06 · Tech Stack
Everything You Need
to Build DebtMap
Scanning Engine
Semgrep OSS
Open source SAST engine. Fast, language-agnostic, runs on every push. Free to use. 3,000+ security rules out of the box for OWASP Top 10.
AI Explanation Layer
Claude API (Sonnet)
Takes Semgrep's raw finding (code + rule ID) → returns plain English explanation, real-world impact, and a specific code fix. The core value-add of DebtMap.
Package Safety
npm / PyPI Registry API
Validate every imported package against official registries. Flag anything that doesn't exist or has zero downloads. Slopsquatting detection at no extra cost.
Code Integration
GitHub App + Actions
GitHub App for repo access. GitHub Actions for PR-level scanning. Octokit for creating PRs with the AI-generated fix automatically applied.
Backend
FastAPI (Python)
Python for seamless Semgrep integration and Claude API calls. FastAPI for async speed. Python is the natural language for security tooling.
Database
Supabase
Scan history, health score trends, user repos, fix status. Row-level security for multi-tenant data isolation. Built-in auth for the dashboard login.
Frontend
Next.js + Tailwind
Dashboard built in Next.js for server-side rendering. Tailwind for rapid UI iteration. Recharts for health score trend graphs. Deploy to Vercel.
Notifications
Resend + Slack SDK
Email alerts when new critical issues are found. Slack webhook integration for Team tier. Resend free tier handles first 3,000 emails/month.
Payments
Razorpay Subscriptions
UPI AutoPay + card for Indian market. Monthly subscription with annual discount option. Webhook for plan upgrade/downgrade events.
